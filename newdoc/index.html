Ki Editor Reference Manual

Technical reference for editor modes, keybindings, and configuration.

1. The Core Model

Structure: Selection Mode → Movement → Action

Ki separates selection mode from movement:

  • Left Hand: Selects the target unit (Word, Line, Syntax Node, Char) or holds an action layer.
  • Right Hand: Executes movement (u/o, j/l, i/k, y/p).

Movement keys behave consistently across all selection modes.

2. Escape & Universal Cancellation

In Ki, returning to Normal Mode or cancelling an active overlay (prompt, popup menu, momentary layer, dropdown) uses a single unified escape behavior:

Key Context Effect
Esc / Ctrl+g / Ctrl+[ Insert Mode Leave Insert mode and return to Normal Mode.
jk Insert Mode Fast two-key escape sequence (within 500ms): erases the j and returns to Normal Mode.
Esc / Ctrl+g / Ctrl+[ Prompt / Picker Close prompt and cancel input.
Esc / Ctrl+g / Ctrl+[ Menu / Momentary Layer Deactivate layer and close legend.
Esc / Ctrl+g / Ctrl+[ Normal Mode Reset multiple cursors and keep only the current primary window.

4. Primary Selection Modes (Contiguous Text Objects)

Primary selection modes are located on the Left Hand in Normal mode. Selecting one immediately selects the current text object under the cursor and sets the context for right-hand movements:

Key Mode Target Unit Key Details
d Syntax Tree-Sitter Syntax Node Selects the largest semantic node at cursor. i goes to Parent node, k to child.
Shift+d Syntax* Fine Syntax Node Selects the smallest AST node at cursor.
a Line Trimmed Line Selects non-empty line content (excluding leading/trailing whitespace).
Shift+a Line* Full Line Selects the full line including leading indentation and trailing newline.
s Word Alphanumeric Word Standard word (identifiers, words). j/l moves over non-symbols.
Shift+s Word* Big Word Whitespace-delimited chunk (equivalent to Vim's W).
w Subword CamelCase / snake_case token Selects individual parts of compound identifiers (e.g. get in getUserName).
Shift+w Char Single Character Character-level movement like a conventional editor.
Shift+e Paragraph Paragraph block Contiguous run of non-empty lines separated by blank lines.

8. Momentary Layers (MoL) Explained

What is a MoL? Marked with ≡, a Momentary Layer activates while holding down a key, and immediately releases on key release (using the Kitty Keyboard Protocol). In terminals that lack release events, simply tap the key and press Esc, Space, or Enter to close.

While holding the layer key, right-hand movement keys apply the layer's verb across the target movement distance.

All Momentary Layers Summary

Key (Hold) Layer Name Mode Scope Tap Action (Single Press) Held Operation
g ≡ Open Normal Change (delete selection & insert) Opens syntactically padded gap / new line and enters Insert mode.
r ≡ Delete/Eat Normal Delete One (delete selection without copy) Directional deletion. Press Space while held to swap to ≡ Eat.
Shift+r ≡ Cut Normal Cut One (copy selection & delete) Directional deletion with clipboard copy.
e ≡ Mark Normal / Space Space e Toggle Selection Mark Mark navigation (j/l local, u/o global) & tab management.
q ≡ Move Hist Normal None Navigates jump history (j/l coarse across files, u/o fine).
b ≡ Multi-cursor Normal None Spawns / cycles cursors (;/h cycle, j/l/i/k add, n delete, m jump).
v ≡ Paste Normal None Directional paste (j/l gap paste, h/; exact paste).
c ≡ Duplicate Normal Copy (copy to clipboard) Duplicates selection directionally (h/; before/after, i/k vert).
t ≡ Swap Normal None Swaps selection with adjacent units of current mode (j/l, m jump swap).
z ≡ Undo/Redo Normal None Coarse undo/redo (j/l) or fine undo/redo (u/o).
Alt+e ≡ Mark Insert Toggle Selection Mark Mark navigation and tab management directly while staying in Insert mode.
Alt+v ≡ Delete Insert None Delete adjacent text directionally without leaving Insert mode.

≡ Open / Insert Layer (g)

Hold g to insert space and transition into Insert Mode:

Key Combo Effect
g (tap) Change: Delete selection and enter Insert mode.
g + h / ; Insert before / after selection.
g + j / l Open gap / new line before / after current item.
g + i / k Open line above / line below.

≡ Delete (r), Cut (Shift+r), & Eat (r → Space)

Layer Action Cluster Behavior
≡ Delete (Hold r) j/l, u/o, y/p Deletes the current selection and everything through the chosen direction target. Tap r deletes single item.
≡ Cut (Hold Shift+r) j/l, u/o, y/p Copies to clipboard first, then deletes through the chosen direction target. Tap Shift+r cuts single item.
≡ Eat j/l, i/k Replaces everything between current selection and target with the content of current selection.
Hold + m Jump Target Combine with Jump: hold r or Shift+r, press m and jump anywhere on screen to delete/cut directly there.

≡ Mark & Buffer Layer (e / Space Space e)

The behavior of e in Normal mode is configurable via "e_normal_mode": "buffer" (default) or "mark":

Default: Buffer Mode ("e_normal_mode": "buffer")

  • e (tap) → Toggle selection mark at cursor.
  • e + j / l → Marked File Tab << (Prev) / >> (Next).
  • e + y / p → Switch to First |< / Last >| marked file tab.
  • e + k / m → Cycle Marked File ↑ / Unmarked ↓.

Alternative: Mark Mode ("e_normal_mode": "mark")

  • e (tap) → Toggle selection mark at cursor.
  • e + j / l → Local mark: jump to previous (j) or next (l) mark in current file.
  • e + u / o → Global mark: jump to previous (u) or next (o) mark across workspace.
  • e + y / p → First local mark |< (y) / Last local mark >| (p).
  • e + k → Toggle Mark File (pin/unpin tab for current file).
  • e + i → Unmark all other files (closes other tabs).
  • e + n → Close current buffer without saving.
  • e + m → Alternate: Jump to previously visited file.
  • e + h / ; → Open new Untitled buffer to the Left (h) / Right (;).

≡ Multi-Cursor (b)

Hold b to spawn, navigate, and manage multiple cursors:

Key Combo Action
b + ; Cycle Forward (Curs →): Move the primary/active cursor to the next cursor.
b + h Cycle Backward (← Curs): Move the primary/active cursor to the previous cursor.
b + j / l Add cursor at previous / next selection match.
b + i / k Add cursor directly above / below.
b + u / o Add cursor at fine previous / next match.
b + y / p Add cursor at first (|<) / last (>|) match.
b + m Jump Add Cursor: use Jump visual letters to place a cursor anywhere.
b + n Delete Cursor: Remove the current primary cursor from the selection set.
b + Space (or tap b) Multi-cursor Menu:
  • l: Keep Primary Cursor Only (dismiss all other cursors).
  • j: Curs All (add cursors to all selection matches).
  • i: Keep Match (filter prompt to keep matching cursors).
  • k: Remove Match (filter prompt to discard matching cursors).

Filtering Active Selections (Modes & Search Syntax)

When in the multi-cursor menu (tap b), pressing j (Maintain Match) or k (Remove Match) opens the filter prompt. Filter inputs accept mode prefixes separated by a space or slash /:

Prefix Search Mode Description & Example
l Literal Case-insensitive literal string match with escaped symbols (e.g. l foo.bar).
c Case-Sensitive Literal match strictly respecting character casing (e.g. c FooBar).
w Whole Word Matches exact whole word boundaries (e.g. w count).
s / cw Strict Whole word boundary + case-sensitive (e.g. s MyClass).
r Regex Unescaped regular expression (e.g. r \d+).
rc Regex Case Regular expression + case-sensitive (e.g. rc [A-Z]+).
rw Regex Word Regular expression + whole word boundary (e.g. rw test\w+).
n Naming Agnostic Matches across conventions: camelCase, PascalCase, snake_case, kebab-case (e.g. n parse_config).

Workflow Transitions & Multi-Step Modal Flows

Because Ki organizes operations into distinct modal sub-menus (MoL legends and momentary layers), performing compound multi-step tasks involves explicit modal transitions. Common scenarios and optimal transition sequences include:

1. Spreading Cursors Across All Marked Lines / Items:

To spawn cursors on all marked locations or lines, switch the active selection target to Mark mode first, then trigger Curs All:

  1. Open the Multi-Cursor menu: hold b and tap Space (or tap b).
  2. Press n (⚲ Local submenu), then press e (Mark). This sets the selection mode to marks and transitions back to editor mode.
  3. Re-open the Multi-Cursor menu: press b → Space.
  4. Press j (Curs All). A cursor is now placed across all marked lines.
2. Scope-Switching and Mode Redefinition:
  • AST Node to Multi-Word Cursors: While in AST Node mode (d), switching to edit all instances of a symbol requires switching mode to Word (s), re-entering b → Space, and pressing j (Curs All).
  • Filtering Selections After Broad Selection: When creating cursors across an entire block or file, use b → Space → i (Keep Match) or k (Remove Match) with search prefixes (e.g. w variable_name) to narrow down cursor placements before entering Insert mode.
  • Surround Enclosure on Multi-Cursors: Once multiple cursors are placed, press , (Surround Menu) → s (Surround) / f (Change Surround) → delimiter to apply enclosure changes across all cursors simultaneously.

Removing Multi-Cursors & Returning to Single Cursor

Ki provides three distinct ways to remove extra cursors or return to a single cursor:

Method Keys Description
Keep Primary Only b → Space → l Instantly dismisses all secondary cursors and returns directly to the active primary cursor in Normal mode.
Delete Current Cursor b + n Removes only the currently active (primary) cursor and steps focus to the next remaining cursor. Can be combined with cycling (b + ; / h) to selectively cull cursors.
Pattern Filtering b → Space → k / i k (Remove Match) prompts for a search query to prune matching cursors; i (Keep Match) keeps only cursors whose selection text matches the query, dropping all others.

10. Surround (,) & Transform (Shift+f)

Surround Menu (,)

Operates on brackets (), {}, [], quotes '', "", ``, and angular brackets <>:

  • s + delimiter → Surround selection with delimiter
  • d + delimiter → Select inside delimiter
  • e + delimiter → Select around delimiter
  • r + delimiter → Delete surrounding delimiter
  • f + old + new → Change surrounding delimiter

Transform Menu (Shift+f)

Instant casing transformation & comments:

  • s → snake_case
  • d → camelCase
  • e → PascalCase
  • f → kebab-case
  • q → UPPER CASE
  • w → UPPER_SNAKE_CASE
  • k → Toggle Line Comment
  • l → Toggle Block Comment

Surround Enclosure Delimiter Mappings

Key Delimiter Pair Key Delimiter Pair
m ( ) Parentheses j ' ' Single Quotes
, [ ] Square Brackets k " " Double Quotes
. { } Curly Braces l ` ` Backticks

Surround Walkthrough Examples

1. Surround Selection:

Select target token (e.g. s for Word, or extend with f) → press , (Surround Menu) → press s (Surround) → press delimiter key (e.g. k for " " or m for ( )).

2. Change Surround (e.g. "hello" → 'hello'):

Place cursor inside the existing quotes → press , → press f (Change Surround) → press k (old delimiter: ") → press j (new delimiter: ').

3. Delete Surround (e.g. [items] → items):

Place cursor inside brackets → press , → press r (Delete Surround) → press , (Square Brackets).

4. Select Inside / Around:

Press , → d → m to select text inside parentheses, or , → e → m to select including the parentheses.

11. Pipe to Shell (Space → l → e)

Pipes the current selection into an external shell command via STDIN, replacing the selection in-place with the process's STDOUT (similar to Vim's !):

  1. Select the target text (e.g. a for Line, d for AST Node, or extend range with f).
  2. Open the prompt: press Space → l (Context) → e (Pipe).
  3. Enter the shell command (executed through bash -c "<cmd>") and press Enter.
Workflow Selection Command Effect
Sort lines Extend line range (f) sort / sort -u Replaces selected lines with sorted lines.
Format JSON snippet AST Node (d) or range jq . Pretty-prints JSON in-place.
Align columns Multi-line block column -t Formats tabular text into aligned columns.
Base64 encode/decode Word (s) base64 / base64 -d Encodes or decodes selection.
Custom Python filter Any selection python3 -c "import sys; ..." Transforms text using inline Python script.
Multi-Cursor Support: When multiple selections or cursors are active, each selection is piped through the shell command independently. Transformations are fully undoable with z → u.

12. Prompts & Nucleo Fuzzy Pickers

All picker dialogs in Ki share fuzzy matching powered by Nucleo:

  • Substrings: Type characters anywhere in filename or path (e.g. ekl matches editor_keymap_legend.rs).
  • Exact tokens: Prefix with single-quote 'pattern to enforce substring match.
  • Prefix tokens: Prefix with ^pattern to match the start of filename or path.
  • Suffix tokens: End with $ to match extension or suffix (e.g. .rs$).
  • Inverse tokens: Prefix with !pattern to exclude items matching the pattern.
  • Multi-term AND: Separate words with spaces (e.g. components 'editor .rs$).
  • Open all narrowed items: Press Ctrl+o or Alt+g to open all currently filtered files/items in the picker and close the prompt.
  • Close all narrowed buffers: Press Ctrl+k or Alt+c in the buffer picker to close and unmark all matching buffers.
  • History: Historical queries display below prompt; navigate with Up/Down.

13. File Explorer (- / File Reveal)

  • _ or Shift+- opens the file explorer rooted at the current working directory (cd).
  • Space → ; in deep Space menu opens the file tree directly by default, or prompts for a directory path first when "filetree_open_with_path": true is set.
  • Pressing Tab on any node in the explorer opens the "Open File (or CD)" prompt rooted at that item.

14. Git Integration & Workflow

Ki embeds native Git operations powered directly by libgit2. Git is not an afterthought or third-party plugin—hunks, branches, and statuses are first-class editor primitives.

Branch & Reference Diffs Modes

Ki supports comparing and jumping against two distinct references:

  • @ (Current Branch): Unstaged / uncommitted changes compared against HEAD of your current branch.
  • ^ (Main Branch): Changes compared against the repository trunk branch (main or master).

Gutter Diff Indicators Visuals

Live diff markers appear alongside the line numbers in real-time:

  • Insert: Highlights newly added lines.
  • Delete: Indicators marking deleted lines.
  • Replace: Modified line ranges.

Git Keybindings & Actions

n then g Local / File Hunk@ (Selection Mode) Selects Git hunks in the current file relative to current branch. Use j/l or u/o to jump between hunks!
n then Shift+g Local / File Hunk^ (Selection Mode) Selects Git hunks in the current file relative to main/master branch.
Space then g / Shift+g Global / Project Repo Hunk@ / Repo Hunk^ Loads all changed hunks across all files into the Quickfix list for multi-file review.
Space + l then g Context Menu Revert Hunk @ Reverts the Git hunk intersecting current selection back to the current branch commit.
Space + l then Shift+g Context Menu Revert Hunk ^ Reverts the Git hunk intersecting current selection back to the main branch commit.

Space + k then g Picker Git Status ^ Fuzzy picker showing files changed against the main/master branch.

17. Configuration Reference & File Locations

Ki supports dual-level hierarchical configuration with full fallback. Global user settings apply everywhere, while workspace settings override on a per-project basis.

Global Configuration User-Wide

Read from your operating system's standard user configuration folder:

  • Linux / BSD: ~/.config/ki/config.json (or .toml / .yaml)
  • macOS: ~/Library/Application Support/ki/config.json
  • Windows: %APPDATA%\ki\config.json (or %LOCALAPPDATA%)

Workspace Configuration Per-Project

Placed in the root directory of your project/repository:

  • .ki/config.json
  • .ki/config.toml
  • .ki/config.yaml

Note: JSON config files support JSON5 extensions (comments with // and trailing commas).

Example Configuration (config.json)

{
  "theme": "VS Code (Dark)",           // e.g. "Catppuccin Mocha", "Gruvbox Dark", "Dracula", "Nord Dark"
  "keyboard_layout": "QWERTY",         // "QWERTY", "QWERTZ", "DVORAK", "COLEMAK", "COLEMAK-DH", "WORKMAN"
  "indent_width": 4,                   // Number of spaces per indentation level
  "indent_char": "space",              // "space" or "tab"

18. Leader Keymap (\) & Custom Shell Scripts

Ki includes a built-in Leader key mechanism invoked via \ (Backslash in Normal mode). It maps a 3×10 matrix corresponding to the 3 main keyboard rows directly to custom shell scripts stored in your scripts/ directory.

Script Locations: Scripts are searched in .ki/scripts/<script_name> (workspace) first, then in ~/.config/ki/scripts/<script_name> (global).

Defining Leader Keys in config.json

The leader_keymap is a 3-row array of 10 items matching the keyboard matrix (Row 1: q w e r t y u i o p, Row 2: a s d f g h j k l ;, Row 3: z x c v b n m , . /):

{
  "leader_keymap": [
    // Row 1: q  w  e  r  t  y  u  i  o  p
    [
      { "name": "Run Tests", "script": "run-tests.sh" }, // bound to \ q
      null, null, null, null, null, null, null, null, null
    ],
    // Row 2: a  s  d  f  g  h  j  k  l  ;
    [
      null, null, null, null,
      { "name": "Git Push", "script": "git-push.sh" },   // bound to \ g
      null, null, null, null, null
    ],
    // Row 3: z  x  c  v  b  n  m  ,  .  /
    [
      null, null, null, null, null, null, null, null, null, null
    ]
  ]
}

Script Input / Output Protocol (JSON over STDIN / STDOUT)

When triggered via \, Ki passes current editor state as a JSON payload over STDIN to your script:

  • current_file_path: Absolute path of the current buffer.
  • selections: Array of all active selections with their content and range (0-based line & column coordinates).

If your script outputs JSON back on STDOUT, Ki executes instructions returned (e.g. replacing selections or showing notification dialogs).
