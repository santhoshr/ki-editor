Kustom Ki: Modifications & Rationale

Log of architectural changes, bug fixes, keybinding customizations, and performance optimizations implemented on the kustom_ki branch.

Feature 1. Universal Escape Alternatives (Ctrl+G & Ctrl+[)
285bc19df, b559a87a2
Motive (Rationale)

Reaching for physical Esc interrupts home-row typing ergonomics. Modals, input prompts, dropdowns, and file pickers bypass mode keymaps, so standard keymap overrides failed to dismiss modals reliably.

Update Note

Intercepted Ctrl+G and Ctrl+[ at top-level event dispatch (App::handle_event in src/app.rs) and translated them directly to KeyCode::Esc before any component or mode handles the key event. Works across Normal mode, Insert mode, menus, prompts, dropdowns, and pickers.

Feature 2. Insert Mode Exit via jk Chord
3a5a57003
Motive (Rationale)

Provides a standard home-row chord to exit Insert mode without requiring JSON configuration shell-outs or external remaps.

Update Note

Added a 500ms timeout state (last_insert_j_press) in App::handle_event. When k is pressed within 500ms of j in Insert mode, the chord triggers mode exit, closes active dropdowns/info panels, and returns to Normal mode.

Bug Fix 3. Clean Undo Rewind on jk Exit
c32fd0c51
Motive (Rationale)

The initial jk implementation issued a Backspace dispatch. In Ki, Backspace is recorded as a coarse edit transaction that pushed an entry onto the undo stack and cleared redo history. In sticky terminal emulators or on undo traversal, the inserted and deleted j lingered in the edit history.

Update Note

Replaced Backspace with a dedicated DispatchEditor::RevertLastInsertChar. It rolls back the fine insert edit that inserted j via undo(true) and discards the inverted record from redo_stack (Buffer::pop_redo_stack), leaving no trace of the typed j in either undo or redo rings.

Performance 4. Screen Diff & Visible-Range Regex Optimizations
cc4b10b3f, 77728bcff
Motive (Rationale)

Scrolling performance felt noticeably sluggish compared to terminal editors like Vim or Kakoune. Profiling identified two bottlenecks: (1) Screen::diff rebuilt a hash-based IndexSet for every cell every frame; (2) syntax highlighting converted the entire buffer to a String and ran regex evaluations across whole files during render.

Update Note
  • Added a direct index-by-index equality fast-path in src/screen.rs when terminal buffer cell counts match, bypassing IndexSet hashing.
  • Restricted editor syntax regex rendering in src/components/render_editor.rs to visible viewport line slices while preserving full matching on title tabs to avoid truncating zero-width delimiters.
Bug Fix 5. Git Hunk Multi-Op Diff Panic
cc4b10b3f
Motive (Rationale)

Viewing or reverting multi-operation Git diff hunks crashed the editor with thread '<unnamed>' panicked at src/git/hunk.rs:102:9: assertion failed: diff_ops.len() <= 1.

Update Note

Removed the single-op assertion in src/git/hunk.rs and iterated over all inline change operations with diff.iter_inline_changes(op), supporting compound Git diff changes cleanly.

Bug Fix 6. Reliable Manual and External File Reload
7cb7f1f21
Motive (Rationale)

Manual "Reload File" (Space j d) and external disk changes failed to update the buffer when timestamps matched or atomic write rename events were omitted by the file watcher.

Update Note
  • In src/buffer.rs, respected the force: true flag in Buffer::reload to bypass cached modification timestamp checks.
  • In src/file_watcher/mod.rs, broadened event filtering to handle atomic replace renames and create events in addition to raw data modification.
  • Set force: true on manual reload in src/keymap.rs.
Feature 7. CLI Multi-File Opening & Dirty Auto-Marking
77728bcff
Motive (Rationale)

Ki opened CLI arguments in preview mode, replacing the current buffer when opening subsequent files. Multi-file command line arguments were unsupported, and editing preview files did not persist them as pinned tabs.

Update Note
  • Updated CLI arguments (src/cli.rs) to accept multiple paths (Vec<String>).
  • Files passed on the command line are opened in the background and automatically pinned into marked_files ([-]), focusing the first file.
  • When a buffer becomes dirty (SetFileDirtyStatus(true)), it is automatically added to context.mark_file(...) so modified previews convert to pinned tabs.
Feature 8. Swapped Picker Keys (f for File, d for Buffer)
77728bcff
Motive (Rationale)

In the Space Pick menu (Space k), d was mapped to File and f was mapped to Buffer. Mapping f → File and d → Buffer (Document) matches intuitive mnemonics.

Update Note

Swapped bindings in space_pick_keymap_legend_config (src/keymap.rs): f now opens FilePickerKind::NonGitIgnored and d opens FilePickerKind::Opened.

Feature 9. Dynamic Tabbar Column Grid & Aligned Indicators
fec00941f
Motive (Rationale)

Opening numerous files caused the tab list to grow into hundreds of wrapped lines, obscuring the buffer. Navigating across tabs caused row elements to shift unpredictably, and tab indicator brackets [-] were misaligned across rows.

Update Note
  • Capped tab bar height between 1 and 5 rows (bounded by 20% of terminal height).
  • Implemented a dynamic column-grid layout in src/components/render_editor.rs: caps cell text to 25 characters without ellipsis and aligns tab brackets [-] vertically column by column.
  • Added zero-padded line numbering (01│) on the left and a dedicated indicator row showing row count on the left and [filename] right-aligned.
  • Silently unmarks deleted/invalid non-file paths (such as symlinked directories) on tab cycling without popup error dialogs.
Bug Fix 10. Complete Tab & Buffer Picker Listing
fec00941f
Motive (Rationale)

The Buffer Picker (Space k d) previously only queried in-memory buffers in layout.get_opened_files(), omitting persisted and marked tabs that had not yet been paged into RAM.

Update Note

In src/app.rs (open_file_picker), merged context.get_marked_files() and layout.get_opened_files() into an ordered IndexSet, ensuring all open tabs and resident buffers appear in the picker.

Bug Fix 11. Real-Time Tab Bar Theme Preview
fec00941f
Motive (Rationale)

When previewing themes via the Theme Picker prompt, the prompt component had focus, treating the background editor as unfocused. As a result, the tab bar fell back to inactive styles and did not update foreground/background colors during theme selection.

Update Note

In src/app.rs (render_component_window), treated SuggestiveEditor as focused while a prompt modal is active so tab bar styles update live as themes are previewed.

Feature 12. Space and Enter Handling in Momentary Layers & Menus
f126af7fe, 718a37cb4, 6b9447f83
Motive (Rationale)

Certain terminal emulators and remote consoles drop key release events, leaving momentary layers "stuck" open without triggering their tap actions (e.g. Delete One). Unconditionally closing on Space broke multi-cursor sub-menus and joint layers (such as r Delete swapping to Eat).

Update Note
  • In src/keymap_override/menu.rs, checked explicit menu keybindings for Space before falling back to closing the menu.
  • In src/keymap_override/momentary_layer/mod.rs, forwarded key events to inner layers first to preserve layer swaps (Delete $\leftrightarrow$ Eat).
  • Allowed both Space and Enter to close momentary layers and execute the single-tap action when no intermediate keys have been pressed.
Bug Fix 13. Small Window Resize Assertion Panic Guard
4d48b6a10
Motive (Rationale)

Splitting terminal windows in a tiling window manager to extreme small heights ($height \le 2$) triggered a panic: assertion failed: result.lines().count() <= dimension.height.saturating_sub(1) in render_editor.rs:411.

Update Note

In src/components/render_editor.rs, calculated max_allowed_lines = dimension.height.saturating_sub(1):

  • If max_allowed_lines == 0, tab bar rendering is suppressed (returns None).
  • If max_allowed_lines == 1, renders only the single active tab line without the indicator row.
  • When max_allowed_lines ≥ 2, clamps total tab rows and indicator row to max_allowed_lines.
Documentation 14. Documentation Overhaul & Reference Guide
c34a5584c, e62d9ace4, 4d8ae4df5, b28416ce5
Motive (Rationale)

Upstream documentation was verbose and philosophical rather than functional. A clean, single-page reference was needed covering all actual keybindings, configuration schemas, and Git workflows.

Feature 15. Keymap Unification: Swap (x), Cut (Shift+R), Search (/)
246de5e0c
Motive (Rationale)

Unify inconsistent layer keys and provide familiar modal text-editing ergonomics. x was previously fragmented across submodes; search required navigating menus instead of standard / and ?; and cut clashed with other multi-cursor operations.

Update Note
  • Unified Swap layer switching strictly to x across momentary layers (Eat $\leftrightarrow$ Delete).
  • Rebound Cut to Shift+R (R) to free up single-key ergonomics.
  • Bound forward and backward search directly to / and ? in Normal mode.
Feature 16. Pipe Buffer / Selection to Shell Command (|)
b07007359
Motive (Rationale)

Provide UNIX-style filter and transform capabilities directly from the editor without switching out to an external terminal multiplexer.

Update Note
  • Bound | to prompt for a shell command string.
  • Pipes the selected text (or entire buffer if no selection) into the command's stdin and replaces the selection/buffer with stdout.
  • Documented usage and examples in Section 15 of newdoc/index.html.
Feature 17. Fallback Alt+/ to Buffer Picker
cb5bfa4d8
Motive (Rationale)

In Ki, Alt+/ acts as a universal cycle key across open split panels, file tree explorers, or auxiliary views. When no auxiliary views are open, pressing Alt+/ did nothing, leaving a dead key chord.

Update Note
  • In src/app.rs and src/layout.rs, added a check on Alt+/: if there is only one view component active, it automatically falls back to opening the Buffer Picker (FilePickerKind::Opened).
  • Enables fast single-chord buffer jumping without needing to open the Space menu.
Feature Bug Fix 18. Picker Multi-Open, Batch Buffer Closure & Reveal Navigation
8d02d443a
Motive (Rationale)

When searching for files or managing open buffers, users frequently need to open all matching search results into marked tabs at once or close multiple buffers matching a query filter. In addition, opening multiple files previously leaked unmarked ghost buffers into memory, causing them to linger after running Unmark Others. Ergonomic quick keys were also needed for file picker and explorer reveal.

Update Note
  • Batch Open: Added Ctrl+o and Alt+g in file/buffer prompts to open all filtered items simultaneously and mark them in the tab bar.
  • Batch Close: Added Ctrl+k and Alt+c in buffer prompts to close all filtered buffers in one step (avoiding conflict with Alt+i/Alt+k page scrolling).
  • Ghost Buffer Purge: Fixed unmark_all_others to explicitly remove backing editors from layout.background_suggestive_editors and sync file watchers so unmarked files do not linger.
  • Navigation Shortcuts:
    • Bound Space → ; directly to the fuzzy file picker (FilePickerKind::NonGitIgnored).
    • Bound - in Normal mode to reveal the current buffer's file or directory in the file explorer.
  • Filter Query Syntax: Documented selection filter modes (l , c , w , s , r , rc , rw , n ) and Nucleo fuzzy tokens (^prefix, suffix$, 'exact, !inverse).
Feature 19. Command Menu on Space & Invocations
2344754a6, ecf2b478a, bbb4507ae
Motive (Rationale)

High-frequency editor actions and tab management originally required navigating deep submenus (e.g. Space j d to reload, Space k d to switch buffers). A unified two-column Command HUD on Space directly exposes common operations while retaining access to all nested menus.

Update Note
  • Command HUD: Pressing Space in Normal mode opens the two-column Command HUD: Commands on the left (f, b, T, B, C, -, _, w, q, v, e, /) and Buffers on the right (j/l prev/next, y/p first/last, k/m cycle, u alternate, s save, a save as, d reload, h/; new tab). Holding e in Command menu triggers the Buffer momentary layer if "e_normal_mode" is "mark", and triggers the Mark momentary layer if "e_normal_mode" is "buffer"; tapping e toggles selection mark.
  • Invocation Key: Configurable via "command_menu_invocation": "Space" (default), "c", "C", or ":". When set to "c", normal mode c (Copy/Dup) moves into the menu under c, and Space opens the original Space menu directly.
  • Space HUD Footer: Displays extended navigation help after Leader: * Pick Keyboard \ Leader - File Tree (current file) shift+-/_ File Tree (cd).
  • File Tree Bindings: Pressing - reveals current file in explorer; _ or Shift+- reveals current working directory (cd) in explorer.
Feature 20. Persistent Hierarchical Bookmarks & Contextual HUD
39ea1914c, bbb4507ae
Motive (Rationale)

Users require fast, persistent access to critical files and project directories across editing sessions without keeping dozens of open tabs. Bookmark menus also need clear, visible key hints on how to assign, nest, and clear entries.

Update Note
  • Simultaneous Dual Engines: Both Bookmarks (nested) and Quick-marks (single) run concurrently without needing a mode switch:
    • Bookmarks (Nested): Stored in ~/.config/ki/bookmarks.json. Invoked by Shift+B (or B in Space Command menu). Supports hierarchical submenus with recursive nesting via = or trailing /. HUD footer: Key/S-Key/Alt-Key Pick file/folder to bookmark, empty path to clear, input = to nest(equals key).
    • Quick-marks (Single): Stored in ~/.config/ki/quick_marks.json. Invoked by : by default (or 1 if command menu is at : or configured via "quick_marks_menu_invocation": "1"). Flat mapping where each key supports as many bookmarks as desired (Vec<AbsolutePath>).
      • Activation by key: If unassigned, opens assign prompt pre-filled with current file. If 1 bookmark configured, activates directly. If multiple bookmarks configured, opens the searchable fuzzy picker to select and activate via Enter.
      • Shift+Key: Opens prompt pre-filled with the current file path to add another bookmark to that key.
      • Alt+Key: Opens editable panel (multi-line editor buffer) in Normal mode and Line selection mode with the first item selected. Allows users to delete or edit one, many, or all bookmarks using standard Ki editor keys (r/x, selections, etc.). Enter activates focused line and saves; Esc saves remaining bookmarks and exits.
      • HUD footer: Key Open/Pick, S-Key Add file, Alt-Key Edit panel.
  • Persistent Storage: Backed by ~/.config/ki/bookmarks.json and ~/.config/ki/quick_marks.json with live disk watcher reload on external file modifications.
  • Invocations & Conflict Resolution:
    • Bookmarks: Configurable via "bookmark_menu_invocation": "B" (default), ":" (or "colon" / "shift+;" / "shift+semicolon"), or "1".
    • Quick-marks: Configurable via "quick_marks_menu_invocation": ":" (default, or "colon" / "shift+;" / "shift+semicolon") or "1".
    • Conflict Resolution:
      • If Command menu is ":": Command gets ":", Quick-marks gets "1", Bookmarks gets "B".
      • If both Quick-marks and Bookmarks are ":": Quick-marks gets ":", Bookmarks gets "1".
      • If both Quick-marks and Bookmarks are "1": Quick-marks gets "1", Bookmarks gets ":".
  • Mnemonic Jumps: Pressing any assigned character (a–z, A–Z, 0–9) instantly opens the file or switches working directory.
  • Searchable Filter: Tab in either HUD opens a Nucleo fuzzy picker displaying all absolute paths with Ctrl+o batch open support.
Feature 21. Mark / Buffer Menu Modality (e_normal_mode)
a31890c34
Motive (Rationale)

Some users prioritize buffer/tab navigation when pressing e in Normal mode, while others prefer granular text mark jumping and custom tab management actions.

Update Note
  • Configurable Modality: Added "e_normal_mode" configuration: "buffer" (default) or "mark".
  • When set to "buffer" (default): e opens the original Buffer menu (j/l prev/next marked tab, y/p first/last marked tab, k/m cycle marked/unmarked).
  • When set to "mark": e opens the customized Mark menu (j/l local marks, u/o global marks, y/p jump to first/last local mark, k toggle mark, i unmark others, n close buffer, m alternate, h/; new tab).
  • Tap Retention: Tapping e continues to toggle a selection mark at the current cursor in both modes.
Feature 22. Explorer Path Prompt, Key Swap & Picker Configs
1be0b0407, 35b82eefb, 115312eaa
Motive (Rationale)

Different workflows require configuring whether the file tree prompts for a directory path, customizing cursor swap keys, or swapping mnemonic keys in pick menus.

Update Note
  • File Tree Prompt: Added "filetree_open_with_path" (boolean, default false). When false, Space → ; opens the file tree directly rooted at the current file or working directory (original behavior). When true, prompts for a path before opening.
  • Picker Swap: Added "pick_menu_df_swap" (boolean, default false). Controls whether Space → k maps f to File and d to Buffer (false), or swaps them (true).
  • Swap / Cut Key: Added "swap_key" ("/" or "x", default "/"). When "/", / triggers cursor swap and x triggers cut. When "x", x triggers cursor swap and Shift+R triggers cut.
  • Navigation Keys: Added "navigation_keys" ("ijkl", "hjkl", or "jhlk", default "ijkl").
    • When set to "hjkl": maps h=j (Left), j=k (Down), k=i (Up), l=l (Right).
    • When set to "jhlk": maps j=j (Left), k=l (Right), h=i (Up), l=k (Down).
  • HJKL / JHLK Configurable Pairs: In both "hjkl" and "jhlk" modes, the roles for the remaining three key pairs are configurable via:
    • "hjkl_y;_action" (or "hjkl_y_semicolon_action" for linter compatibility): "insert" (default), "fl", or "np". Controls keys y and ;.
    • "hjkl_io_action": "np" (default, Prev/Next), "insert", or "fl". Controls keys i and o.
    • "hjkl_up_action": "fl" (default, First/Last), "insert", or "np". Controls keys u and p.
    Defaults: y/; → Insert ends, i/o → Prev/Next, u/p → First/Last. On collision or duplicate mappings, reverts cleanly to default after issuing a warning.
  • JHLK Inversion: Added "jhlk_np_rl_inverse" (boolean, default false). When true in "jhlk" mode, inverts Right/Left motions (j → Right, k → Left) and inverts the configured Next/Previous pair (Next/Previous). Up, Down, First/Last, and Insert actions remain unchanged.
  • Safe Quit Workflow: When quitting (q), all clean buffers are automatically closed and unmarked. If all buffers were clean, Ki exits immediately. If any buffers have unsaved edits, Ki focuses the first unsaved buffer and displays a warning prompt.
  • Persistent Recent Files & Folders Pickers: Ki tracks visited files and directories in ~/.config/ki/recent.json. Bound ' in Normal mode to open the persistent Recent Files filter (MRU order, fuzzy matching, Ctrl-O batch open) and ' in Command menu to open the persistent Recent Folders filter (MRU order, changes active working directory on selection with confirmation notice).
  • Vim-Style Dot Repeat: Bound . (period) in Normal mode to repeat the most recent editing change at the current cursor / selection location. Supports insert at either end (h start / ; end without replacing target selection), explicit change replacement (g tap), open commands (g open above/below/gap + typed text), cut & delete menus (x/r), eat (r), swap (t), paste (v), duplication, surround, indent/dedent (L/J), align (Y/P), join (I), break (K), and comment toggles. Navigation and searches do not alter the repeat buffer. Moved Parent Line motion from . to Shift+. (>).
